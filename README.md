# AI VTuber Personal Assistant

A local-first personal AI companion with a VRM avatar, persistent memory, personality, emotions, voice interaction, and eventually computer tools.

## Current Goal

Build the project incrementally with a ₹0/local-first setup.

Initial MVP:

- React + TypeScript + Vite frontend
- Three.js + `@pixiv/three-vrm` VRM avatar
- Node.js + TypeScript backend
- Local LLM through `llama.cpp`
- SQLite memory
- Structured AI responses
- Emotion-driven avatar expressions

## Development Philosophy

1. Build one subsystem at a time.
2. Keep interfaces modular.
3. Prefer local/free components.
4. Do not add infrastructure before it is needed.
5. Do not implement future phases early.
6. Keep the application understandable and debuggable.
7. Never give the AI unrestricted computer access by default.

## Planned Phases

1. Foundation
2. VRM Avatar
3. Local LLM
4. Personality
5. Emotion System
6. Memory
7. Voice
8. Real-time Conversation
9. Tools / Agent
10. Proactive Behavior
11. Vision
12. Polish

The first milestone is Phase 6: a conversational local AI with a VRM avatar, personality, emotions, and persistent memory.
